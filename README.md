# NXTFLIX

A Netflix-style movie discovery app built with React 19, TanStack Start (SSR),
TanStack Router, and Tailwind CSS v4.

## Features

- Server-rendered routes via TanStack Start
- Browse movies by category with a carousel-based UI
- Movie detail pages
- Watch Later list with persisted state via context
- Authenticated routes with token-based login

## Tech stack

- React 19 + TanStack Start / TanStack Router
- Tailwind CSS v4 + shadcn/ui (Radix primitives)
- TanStack Query for data fetching
- TypeScript, ESLint, Prettier

## Getting started

```bash
npm install
npm run dev
```

The app runs at http://localhost:8080

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the build
- `npm run lint` — lint the project
- `npm run format` — format with Prettier
